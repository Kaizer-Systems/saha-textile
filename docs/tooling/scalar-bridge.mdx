This scaffold publishes the current generated OpenAPI evidence with **Test Request** enabled. The deterministic 2026-08-18 artifact contains **95 paths and 111 operations**, including split health probes, verified storefront signup/provider/account flows, admin authentication and authority, CRM, notifications, privacy, catalogue, cart, order, currency, promotion, and `GET /auth/csrf`. The runtime `ApiErrorResponse` envelope and request ID are implemented platform behavior, but they are not yet represented as operation response schemas or examples. Complete request and response contracts, per-operation cookie-session, CSRF, audience and permission semantics, idempotency, side-effect examples, CI drift proof, and an approved HTTPS non-production target remain open.

Test requests never receive a privileged token or security bypass from the portal. They target only the server URLs present in the generated OpenAPI document and remain subject to normal CORS, authentication, CSRF, authorization, ownership, and rate-limit enforcement. Login, OTP verification, and refresh issue a session-bound readable CSRF cookie; copy its value into `x-csrf-token` for state-changing requests. For an active session, `GET /auth/csrf` follows Policy B (preserve a still-valid bound token; rotate only to recover a missing/desynced cookie).

Authentication remains a partial capability. Session rotation/revocation, CSRF, audience isolation, verified signup, email/phone password and OTP login, Google/Facebook verifiers, identity and password/session management, account self-service, guest-cart adoption, admin recovery/PIN/invites/resume, Account Security and idle lock, the closed **89-code** permission registry, authority controls, operator bootstrap, consent/privacy, and ownership checks are implemented. Provider activation/browser proof, real-browser PIN-login proof, pending-intent continuation, and granular adoption by older privileged routes remain incomplete. Test Request provides no bypass for any runtime control; the current generated HTTP server URL does not match the repository's HTTPS local cookie topology.
