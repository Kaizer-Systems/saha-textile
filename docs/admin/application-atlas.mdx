## What scaffolded means here

For most admin feature families, scaffolded means:

- A lazy route exists.
- A standalone component and template exist.
- List and detail queries exist.
- The service reads a typed JSON file.
- Table and form interaction is present.
- Create, update, delete, approve and bulk actions are absent, have no effect, or only navigate.

Features that use the API are listed in [Capabilities](./overview#capabilities).

## Operational readiness test

An admin workflow is complete when:

1. The API contract is validated at the boundary.
2. Authentication uses the cookie-session gateway.
3. The API authorizes the action and the target resource.
4. Reads and writes use real endpoints.
5. The UI handles pending, success, validation, conflict, failure and retry states.
6. Audit requirements are met.
7. Tests cover the critical operator path.
8. Portal pages are updated.
