The Component Forge opens one application-segregated Angular renderer. Storefront, Admin, and Shared stories retain their own decorators while inheriting the portal’s common visual language.

The renderer contains 119 named states. Its compiler gate accounts for all 139 reusable components across 282 Angular components (Storefront 106/106; Admin 33/33), while route and page orchestration remains assigned to integration and Playwright coverage. The Storefront full-page Loader is an intentionally permanent component specimen.
