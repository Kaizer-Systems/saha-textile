This page opens TypeDoc, the TypeScript reference. It covers exported contracts, signatures, schemas, interfaces, ports and pricing functions.

Its two entry points are `packages/contracts/src/index.ts` and `packages/core-domain/src/index.ts`. Persistence models and repository implementations are not included, because adapters sit outside this boundary. The build treats warnings as errors and validates links.

For HTTP operations, use [Scalar](/tools/scalar). For architecture and workflows, use the portal guides.
