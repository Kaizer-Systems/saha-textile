## Markers

| Marker       | Meaning                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| **SAFE NOW** | Current locks are sufficient for final implementation.                                                              |
| **SEAM NOW** | Build contracts, ports, indexes, stubs, and reversible policy boundaries; final behavior waits for an owner answer. |
| **BLOCKED**  | Do not allocate irreversible identifiers or ship final policy behavior.                                             |

## Implementation gates

| Gate                                                           | Decision source                    | Blocks                                                                   |
| -------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------ |
| **G-NUM-ORDER** — order/tax-invoice numbering                  | `DEC-NUMBERING`                    | Issuing customer-facing order/tax-invoice numbers and final invoice PDFs |
| **G-NUM-PI** — purchase-invoice numbering                      | `DEC-NUMBERING`                    | Posting purchase invoices with final business numbers                    |
| **G-CORE-CONTRACTS** — core/contracts direction — **RESOLVED** | owner decision: type-only coupling | Nothing; ESLint-enforced and unblocked                                   |
| **G-I18N-ROUTES** — canonical locale URL law                   | `DEC-I18N-ROUTES`                  | Final canonical/hreflang/redirect behavior                               |
| **G-IMG-PX** — image dimensions and ingest limits              | `DEC-IMG-PX`, `DEC-MEDIA-CAPS`     | Final sharp presets, upload ceilings, and responsive-source enforcement  |

Other open decisions block only their own final policy engine. Reversible schemas, contracts, ports, and seams may proceed.

## Cross-cutting invariants

- Angular never connects to MongoDB, Meilisearch, Spaces, or providers directly.
- `packages/contracts` owns shared Zod shapes.
- Core may consume contract shapes through `import type` only and stays runtime-pure.
- MongoDB is self-hosted 8.3 with replica-set transactions.
- MongoDB is source of truth; Meilisearch is derived and rebuildable.
- Canonical price is INR and final money math runs server-side.
- Browser auth uses cookies plus CSRF; no browser token happy path.
- Object-level authorization is mandatory.
- Admin mutations are audited.
- Provider integrations remain behind ports.
- Production providers wait for approved credentials and current official documentation.
