# Kept Surface Atlas — Admin strip-down memory

> Living inventory of what the admin app **kept** after theme strip-down, and how each
> surface is classified under the **existing** permission architecture (`PERMISSION_CODES` →
> roles → effective `GET /auth/admin/me` → AuthStore). **Not** mock `account.json` ACL.
>
> Recovery for keep-\* chrome: `vendor/` Fastkart or git history — never reintroduce mock ACL.

Last updated: 2026-08-14

## Classification legend

| Tag           | Meaning                                                                  |

## Permission / AuthStore

- Registry expanded 2026-08-14 to **103** codes (menu ∪ in-page gates ∪ former mock permission names).
- System administrator role seed = full `PERMISSION_CODES`; re-run `pnpm --filter @saha-textile/adapters-db-mongo seed:system-roles` after registry growth.
- `GET /auth/admin/me` returns **effective** permissions (embedded ∪ active role assignments) so AuthStore matches what SessionGuard uses for API checks.
- Do **not** restore `account.json` as ACL. File deleted when unused.
