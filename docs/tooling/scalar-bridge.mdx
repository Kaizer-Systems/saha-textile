This page opens Scalar, the HTTP API reference. It renders the generated OpenAPI document and includes **Test Request**.

Test requests receive no privileged token. They target only the server named in the document, `https://localhost:4000`, and normal CORS, authentication, CSRF, authorization, ownership and rate limits apply. To change state from a session, copy the token from `GET /auth/csrf` into the `x-csrf-token` header.

The document lists every route but does not include full schemas or per-operation security. See [OpenAPI and Scalar](/api/openapi-and-scalar) for usage and limitations.
