This scaffold publishes the current generated OpenAPI evidence with **Test Request** enabled. The deterministic 2026-08-13 artifact contains **62 paths and 69 operations**, including split health probes, storefront/admin authentication, email verification, admin recovery/invites/resume, privacy routes, admin role/permission/user-authority operations, and `GET /auth/csrf`; public product listing has no `status` query parameter. The uniform runtime `ApiErrorResponse` envelope and request ID are implemented platform behavior, but they are not yet represented as operation response schemas or examples. Complete request and response contracts, per-operation cookie-session, CSRF, audience and permission semantics, idempotency, side-effect examples, CI drift proof, and an approved non-production target remain open.

Test requests never receive a privileged token or security bypass from the portal. They target only the server URLs present in the generated OpenAPI document and remain subject to normal CORS, authentication, CSRF, authorization, ownership, and rate-limit enforcement. Login, OTP verification, and refresh issue a session-bound readable CSRF cookie; copy its value into `x-csrf-token` for state-changing requests. For an active session, `GET /auth/csrf` follows Policy B (preserve a still-valid bound token; rotate only to recover a missing/desynced cookie).

Authentication remains a partial capability. Session issue, refresh and revocation, session-bound CSRF, audience isolation, storefront password/OTP/email-verification flows, admin recovery/password/PIN/invite/HTTP-resume flows, Account Security and idle soft-lock resume, the closed **103-code** permission registry, active role-assignment resolution, deny-by-default administration, no-delegation/last-admin/offboarding controls, operator-only first-admin bootstrap, permission-version checks, consent and privacy seams, order BOLA, cart Principal/`st_guest` ownership, and transactional order-create cart adoption are implemented. OAuth verification, real-browser PIN-login proof coverage, and guest-to-user merge remain incomplete. Test Request provides no bypass for any runtime control.
