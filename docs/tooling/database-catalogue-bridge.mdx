This page opens the database catalogue, generated from the Mongoose models. It covers every model, with fields, defaults, enums, select rules and indexes.

Excluded-by-default fields, such as hashes and tokens, are named but left out of synthetic examples. `Mixed` fields are marked as temporary. Generation never connects to a database.

For relationships and planned collections, use [Schema Nebula](/database/schema-nebula).
