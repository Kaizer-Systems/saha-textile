# Every name that must have a value in secrets/api.env before a deploy starts.
# MEILISEARCH_API_KEY is absent on purpose: bin/deploy.sh reads it from the search server.
# Tags after a name, space-separated:
#   server-only       required on every server (staging, production, a dev server) but not for a
#                     release on this computer (DEPLOY_ENV=local): there, without it, the API logs the
#                     message instead of sending it (owner, 2026-11-20: no fake keys; this computer only).
#   may-deploy-blank  a server deploy may still go ahead with it blank, but only when the deploy names
#                     it (`--allow-blank NAME`, the Release Console's "deploy with these blank"; owner,
#                     2026-11-21). The release records it in allowed-blank.txt and tells the API in
#                     RELEASE_ALLOWED_BLANK; the API then refuses that service's work (no message
#                     sent, no upload) instead of refusing to start. Untagged names can never be blank.
