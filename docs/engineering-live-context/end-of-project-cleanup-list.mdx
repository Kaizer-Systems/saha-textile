# End-of-Project Cleanup List — Saha Textile

**Owner rule (2026-11-16):** pieces that a new build replaces or leaves unused are **not removed during the build**.
They stay in the code, working where they still work, and are listed here. One cleanup pass at the end of the
project removes them, after the owner reads this list. Adding a line here is how a removal is proposed; nothing on
this list is removed without the owner's typed go-ahead at that time.

Each line names the files, what replaced the piece, and what the removal also touches.
