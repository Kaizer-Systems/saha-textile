# Payments

Currency selects a gateway role. INR uses the Indian online-gateway role. Any other enabled currency uses the PayPal role. The current INR preference is CCAvenue, with Razorpay as the preferred successor. `DEC-INR-GATEWAY-TIMING` is unanswered. No payment adapter is in this repository. `PaymentGatewayPort` defines `createPayment` and `verifyCallback` only.

The business rules for orders, attempts, and callbacks stay on [Payment and order lifecycle](/business-flows/payment-and-order-lifecycle). This section holds the provider notes.

Every gateway landing page has the same two sections: **1. Company-provided documentation**, a faithful reference from the vendor's own kit, and **2. Endpoints we use**, the calls this project makes, with sample requests and responses and where in the project each one is used.
